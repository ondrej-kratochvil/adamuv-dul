# Adamův důl

Čtecí hra pro prvňáka ve stylu Minecraftu. Hra řekne písmeno nebo slabiku a dítě kope do správné kostky. Za každé kolo přibude díl domu, postupně lepší krumpáče.

- Písmena: A Á E É I Í O Ó U Ú Ů Y Ý, M, L, S
- Slabiky: M, L, S + samohlásky
- Hlas: předčítání prohlížeče (čeština), postup se ukládá v zařízení

Hra je jeden soubor `index.html`, běží na GitHub Pages.
